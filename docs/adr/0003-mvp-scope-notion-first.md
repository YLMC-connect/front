# ADR 0003 — MVP 범위는 Notion 최신 정의 우선

> 상태: 수락  
> 날짜: 2026-05-22

## 맥락

로컬 `PLAN.md`에는 삶공부와 중보기도가 초기 탭/Phase에 포함되어 있었지만, Notion의 최신 “열린문커넥트” 기획은 MVP를 더 작게 정의합니다. 현재 백엔드 Swagger에서도 앱용 API는 인증 일부만 확인되고, 나눔/소모임/기도/삶공부 API는 아직 없습니다.

## 결정

MVP 범위는 Notion 최신 기획을 우선합니다.

- MVP 포함: 회원가입, 로그인, 홈, 나눔, 소모임, MY 기초, 이미지 선택/미리보기
- MVP 제외: 비밀번호 찾기, 가입코드 입력/검증, 사용자 차단, 푸시 알림, 실제 API 연동
- 중보기도와 삶공부는 MVP가 아니라 v1 범위로 분리합니다.
- 나눔/소모임은 `services -> mocks` 구조로 먼저 구현하고, 실제 API가 생기면 service 레이어만 교체합니다.

## 영향

- MVP 앱 탭은 홈 / 나눔 / 소모임 / MY 4개로 시작했습니다.
- `app/(tabs)/prayer`와 `app/(tabs)/life-study`는 ADR 0004의 v1 범위에서 추가합니다.
- 이미지 업로드는 실제 업로드가 아니라 `expo-image-picker` 기반 로컬 선택/미리보기까지 구현합니다.
- 향후 실제 API와 파일 업로드 스토리지가 확정되면 별도 ADR로 백엔드 및 업로드 파이프라인을 결정합니다.
